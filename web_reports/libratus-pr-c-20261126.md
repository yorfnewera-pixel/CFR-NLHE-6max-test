# PR C: схема HU20 + V1 — промежуточная проверка

Исходный commit: `7696cf318f6be4f0dd8a328f9f53dc3bd869c74a`.
Изменения не закоммичены. Полная сборка таблиц и обучение не запускались.

Контрольный архив совпал с SHA-256 из журнала восстановления:
`2b7e5f8bf41ebdd8f8a9f8dcd5ed0d1d174e865ab62c49962bea4089a6241f27`.
Checkpoint размером 441190007 байт совпал с SHA-256
`e96468dada80e752b847da69cb0e36283acc3263d0cfceda35e76f7f47e325ce`;
заголовок подтверждает HU20, меню V1 и K50. Три хеша таблиц совпали с
`identity.card_tables`. Rust потоково проверил заголовок и все 8 303 507 строк
checkpoint; это проверка чтения, а не восстановление полного состояния в памяти.

Новая схема использует полное каноническое представление флопа, отдельный тег
и ID turn/river. Её перечисление отклоняет другие сочетания игры и меню.
Checkpoint связывает два хеша таблиц, карту OCHS и версию канонизации; в
тесте сохранены и восстановлены заданные значения одной записи, проверены
несовпадения хешей, карты, версии и меню и экспорт одной записи. Новые ключи
Rust/Python совпали для всех четырёх улиц одной фиксированной раздачи с
тестовыми назначениями. Это не проверка рабочих таблиц полной колоды.

В WSL прошли пять адресных Rust-тестов новой схемы; Python: 68 тестов
ключей и читателей таблиц, один тест исключён из запуска. Тест отсутствующего
ключа прошёл отдельно. Исходная и изменённая ревизии прошли одни и те же
проверки паритета старых v1/K50 на фиксированных тестовых раздачах.
Проверены явные отказы читателей Rust и Python для `ranks=13`.

## Ограничения и оставшаяся работа

Новый Rust-контур создаёт таблицы только внутри тестов: рабочего пути
загрузки таблиц и resume новой схемы пока нет. Обычный Python-загрузчик
политики также пока отвергает новую схему; K50-загрузчик явно её отвергает.
Следовательно, интеграция потребителей и рабочая загрузка не завершены.
Нужны отдельные проверки bench, прямого матча, LBR, search и web runtime.
Полнота классов для `ranks=13`, рабочие таблицы и проверки с их участием
остаются до квалификации полной колоды. Обучение и сравнение с продолжением
CFR требуют отдельного разрешения.
