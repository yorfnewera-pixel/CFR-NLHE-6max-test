## Манифест и публичное чтение

Python проверяет тип `working_tree_dirty`, диапазон `seed` как u64 и непустую строку `code_revision`. Публичный Python-конструктор требует манифест, в том числе отвергает явный `None`; непроверяемый Rust `read` оставлен только внутри тестов. Публичный Rust `read_verified` требует манифест.

`python -m scripts.verify_libratus_tables native/hu20-buckets/target/release/hu20-buckets.exe <каталог>` выполнен для обоих mean-каталогов и обоих median-каталогов. На каждой таблице оба читателя приняли валидный манифест и отвергли отдельные JSON-подмены `working_tree_dirty="false"`, `seed=-1`, `code_revision=123`, отсутствующий файл манифеста, изменённый байт ID и удалённый класс с пересчитанными счётчиком и SHA-256. Дополнительно проверены неверные magic и street. Rust-тест манифеста закрепляет те же три типа JSON; Python имеет независимый unit-тест проверки типов и проверку реального файла, которая пропускается при отсутствии локальных артефактов.

В предыдущем отчёте Terra две подмены были записаны и проверены с неверными типами. В него внесено исправление: допустимые Rust булево `false` и строка `"123"` не являются ошибочными значениями в исходном плане.
