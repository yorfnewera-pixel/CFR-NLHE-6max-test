# OCHS-8 PR A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать и квалифицировать OCHS-8 river-признак без изменения K50-контроля, форматов или CFR.

**Architecture:** Карта OCHS переводит физическую стартовую руку в одну из восьми неизменяемых групп. Новая `river_ochs_equities` повторяет асимптотику `river_equities`: ранги и группы рук соперника вычисляются один раз, затем блоки равных рангов и счётчики карт дают exact card removal. Медленный прямой перебор существует лишь как независимый oracle тестов.

**Tech Stack:** Rust 2021, Rayon, Cargo unit tests.

**Spec:** `docs/superpowers/specs/2026-11-19-ochs-pr-a-design.md`; `articles/Libratus_buckets/EMD.md`; `articles/Libratus_buckets/План PR A OCHS.md`.

## Global Constraints

- Изменять только `native/hu20-buckets/src/lib.rs`, `articles/Libratus_buckets/EMD.md` и новый отчёт `web_reports/libratus-ochs-pr-a-20261119.md`.
- Не изменять Python, trainer, CFR, checkpoint, `RiverTable`, формат `HU20BKT1` и данные K50.
- Контекст остаётся `hole + current board`; история появления улиц не добавляется.
- Пустая группа использует только `uniform-equity-fill-v1`: битово то же scalar uniform equity, что возвращает `river_equities`.
- Полные генерации таблиц и обучение запрещены; разрешены unit-тесты на малой колоде и заданных river-досках.
- Оригинальный источник групп — Johanson et al., AAMAS 2013, Table 1; номера `1..8` переводятся во внутренние `0..7`.

## Review Focus

- Канонический источник карты — визуальный Table 1 в PDF; Markdown служит вспомогательной транскрипцией, в которой метки строк `2..9` примыкают к цифрам значений (Task 1).
- Руки hero и opponent не пересекаются; исключение двух hero-карт не вычитает пару hero дважды (Task 3).
- Равные showdown-ранги, включая board plays, дают ровно половину очка (Task 3).
- Нулевая доступность группы возвращает scalar equity, а не `0`, `0.5` или `NaN` (Task 4).
- Глобальная перестановка мастей сохраняет группу и все восемь компонент (Tasks 2 и 4).
