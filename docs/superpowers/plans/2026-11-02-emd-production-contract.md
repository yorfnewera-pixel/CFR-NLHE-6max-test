# EMD Production Contract Proposal

**Цель:** безопасно заменить per-edge фильтр `1e-9`, гарантируя выход с результатом либо типизированной ошибкой, но не обещая успех для каждого допустимого `f64` входа.

**Минимальный diff:** в `try_emd` считать residual capacity допустимой при `> 0.0`; добавить варианты `EmdError::{NoPath, NoProgress, IterationLimit, IncompleteTransport}` с диагностическими полями. Сохранить `try_emd -> Result<f32, EmdError>` и существующее обогащение `EmdContextError`; launcher получает неуспешный процесс/статус при `Err`, без panic и без таблиц/успешного `status.json`.

**Успех:** только если одновременно `required_mass - delivered <= tolerance`, сумма source residual и сумма demand residual не больше tolerance, а стоимость конечна. Для нормированных `f32` распределений в масштабе единицы предлагается `tolerance = 64 * f64::EPSILON * dimension`: это консервативная граница порядка операций `f64`, не допуск на пользовательскую массу. Для ненормированного внешнего API сначала выполняется текущая нормировка; при другом масштабе либо иной арифметике допуск нужно пересмотреть.

**Защитные исходы:** `NoPath` — sink недостижим; `NoProgress` — amount не положителен/неконечен либо не изменяет delivered или хотя бы одну path capacity; `IterationLimit` — исчерпан конечный бюджет; `IncompleteTransport` — цикл завершился, но не выполнены все три проверки успеха. Ни один не возвращает частичную стоимость как `Ok`.

**Бюджет:** `4 * (2 * dimension + 2)^2` итераций. Это квадратичный диагностический предохранитель относительно числа вершин residual-графа: достаточный запас для малых test-only случаев, но только гарантия выхода с ошибкой, не доказательство успешного решения всех допустимых задач.

**Критерии приёмки:** fixture ranks=5 и малые остатки завершаются с oracle-cost; invalid input остаётся `Err`; тесты покрывают `IterationLimit`, `NoProgress` и `NoPath` через test-only инъекции; launcher не записывает успешный статус при любой `Err`; полный `cargo test`, `cargo fmt --check`, `git diff --check` зелёные.

**Ограничение:** до отдельного согласования production-патча нет доказательства, что `f64` solver всегда достигает успеха до бюджета.
