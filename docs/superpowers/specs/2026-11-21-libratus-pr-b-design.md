# PR B — малые таблицы Libratus-inspired buckets

## Назначение

Продолжить после завершённого PR A: построить только малые экспериментальные
turn/river-таблицы на малой колоде при `K=50` и `K=200`. Turn использует CDF
equity и L1, river — OCHS-8 и L2. Это проверяет детерминированный pipeline
кластеризации и формат, не меняя K50-контроль, `HU20BKT1`, CFR, checkpoint
или обучение.

## Границы

- Полный build, `K=1_000/5_000` и обучение запрещены.
- Mean для CDF-центров — основной режим, совместимый по смыслу с turn
  `equity-histogram-k50-v1` при `K=50`.
- Median — отдельный экспериментальный режим с собственным именем в
  манифесте; правило для чётного веса едино для всех координат.
- EMD — сумма абсолютных разностей CDF без множителя ширины бина; равенства
  разрешает `first_minimum_emd`. River OCHS использует L2.
- Новый формат и CLI называются `LibratusBucketTable`, `HU20LIB1` и
  `--abstraction libratus-ochs`; они не связаны с existing `potential`.
- Параметры первого выпуска: `ranks=7`, `seed=2026112101`, три рестарта,
  sample до `20_000` с replacement и вероятностью пропорциональной весу;
  такой sample кластеризуется без весов. При `N ≤ 20_000` используется полное
  множество с исходными весами. Максимум 50 итераций, остановка при смене
  менее `1e-4` общей массы; пустой кластер сохраняет предыдущий центр.
- Побеждает рестарт с минимальной взвешенной ошибкой на полном множестве;
  при равенстве побеждает меньший индекс рестарта.

## Подходы

1. Переиспользовать единственный существующий формат K50. Отклонён: нарушает
   неизменность `HU20BKT1` и смешивает контроль с экспериментом.
2. Отдельный формат и явный манифест, но только mean. Подходит контролю, но
   не позволяет воспроизводимо сравнить median.
3. **Выбранный:** отдельный формат и манифест с двумя явно названными
   режимами CDF-центров. Mean остаётся основным, median измеряется отдельно;
   river кластеризуется отдельным OCHS-8/L2 pipeline.

## Реализация и проверки

Сначала отдельный commit закрывает отчёт PR A: фиксирует commit `9550239`,
финальный тестовый прогон и восемь сертификатов; журнал EMD заменяет
устаревшее выборочное измерение точным сертификатом. Далее добавляются малые
builder/reader и тесты: инварианты CDF, правило median, tie-break,
регрессия turn-mean с настоящим путём `--abstraction equity` K50, OCHS-8/L2,
weighted sampling, потоковое назначение и повторяемость SHA-256. Отчёт
сравнит mean и median по полной взвешенной L1 ошибке CDF, river по полной
взвешенной L2 ошибке, взвешенным размерам бакетов, пустым кластерам,
итерациям и времени; он также зафиксирует непереносимость river-метрик
`ranks=7` из-за fallback отсутствующих групп. После отчёта работа
останавливается до решения владельца о PR C.
