# Дизайн PR A: признаки OCHS-8

## Намерение

Доказать корректность river-признака OCHS-8 до изменения форматов таблиц,
информационных ключей или логики CFR. Это создаёт проверяемую основу для
следующего этапа кластеризации и не затрагивает контроль `equity-histogram-k50-v1`.

## Границы

- Изменяется только `native/hu20-buckets/src/lib.rs` и тесты в нём.
- Добавляются неизменяемая карта восьми опубликованных OCHS-групп и публичная
  функция расчёта восьми conditional equity на готовой доске.
- Поддерживается контракт `hole + current board`; история улиц не добавляется.
- Не изменяются Python, trainer, CFR, checkpoint, `RiverTable`, форматы K50 и
  полные таблицы. Полные генерации и обучение не запускаются.

## Рассмотренные подходы

1. **Основной: быстрый расчёт рядом с `river_equities`.** Один проход строит
   ранги и группы совместимых рук соперника, сортирует их и использует блоки
   одинаковых рангов и счётчики карт. Это сохраняет точный card removal без
   квадратичного перебора для каждой hero-руки.
2. **Прямой полный перебор.** Оставить его только независимым test-oracle:
   он проще для проверки, но слишком дорог как производственный путь.
3. **Замена scalar-equity существующей функцией.** Отклонена: сломает K50 и
   не содержит условной информации восьми групп.

Выбран подход 1; подход 2 служит только тестовым эталоном.

## Инварианты и проверки

- Таблица групп покрывает 169 preflop-классов ровно один раз; номера из
  публикации `1..8` переводятся во внутренние `0..7`.
- В каждой компоненте учитываются лишь допустимые физические руки соперника;
  ничья даёт половину очка.
- Пустая после удаления карт группа получает scalar uniform equity в точности
  по правилу `uniform-equity-fill-v1`.
- Все компоненты находятся в `[0, 1]` и инвариантны к глобальной перестановке
  мастей.
- Независимый brute-force oracle покрывает split-pot, flush/straight и
  блокеры. Отдельный малоколодочный тест измеряет взвешенную долю пустых групп
  и останавливает работу перед PR B, если она превышает `0,01 %`.

## Критерий готовности

Только после зелёных тестов OCHS, неизменной scalar-регрессии и отчёта с
фактическими долями пустых групп допустимо переходить к PR B. Решение о
кластеризации, форматах и подключении к CFR в этот PR не входит.
